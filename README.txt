The site has five visible navigation tabs/pages: Home, Define, Manage, Deliver, and Assess.

A separate single-file version is also provided:
Houston_High_School_ASCA_Standalone.html

The standalone version embeds the CSS and portrait in one HTML file, so it can be opened by itself without any other files. The multi-page ZIP is the better version for hosting because it uses separate pages.

Before submitting:
1. Open every navigation tab/page.
2. Confirm the public host URL works in a private/incognito window.
3. If you have your exact Week 6 ASCA Professional Standards & Competencies Assessment results, update the Assess page with those exact personal results.
4. Do not add nonfunctional buttons or links.
